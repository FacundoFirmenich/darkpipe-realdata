# Upstream AION evidence notice

This directory preserves a bounded subset of the AION Collaboration deposit:

- Charles Baynham and the AION Collaboration, “Data and code for ‘A Prototype Differential Atom Interferometer for Fundamental Physics’”, Zenodo, DOI [10.5281/zenodo.19592552](https://doi.org/10.5281/zenodo.19592552).
- Associated article: C. F. A. Baynham et al., Nature 654, 622–628 (2026), DOI [10.1038/s41586-026-10617-1](https://doi.org/10.1038/s41586-026-10617-1).
- Date accessed: 2026-08-25.

Zenodo identifies the record as open and licensed `CC-BY-4.0`. The exact Creative Commons Attribution 4.0 legal text is stored as `CC-BY-4.0.txt`. The deposited bundle also contains an upstream MIT notice, preserved byte-for-byte as `upstream/bundle_LICENSE.txt`, covering the AION software bundle.

DarkPipe renamed selected members only to avoid Windows path-length failures. `source_manifest.json` maps every stored name to its original archive path, byte count and SHA-256. File contents were not modified. The derived `run/` receipt and DarkPipe source code are original DarkPipe work under `GPL-3.0-or-later`; upstream evidence is not relicensed.

Changes made by DarkPipe: selection from the archive, storage-name aliases, independent integrity/schema validation, preregistered calculations E1/E2, Spanish report and diagnostic figure.
